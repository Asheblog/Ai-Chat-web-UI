# 移除 Azure/Ollama 支持实施计划

**目标：** 删除 Azure OpenAI 与 Ollama 专属协议支持，完成代码与 UI 审查，验证后合并 main、推送并跟进镜像构建。

**已确认边界：** 保留历史对话与存量连接记录；停止列出、调用、导入和编辑旧协议连接。保留 OpenAI Chat Completions、OpenAI Responses、Google，以及基于 OpenAI 的交错思考配置。无协议兼容层，不自动将旧连接改成其他协议。

**技术栈：** TypeScript、React/Next.js、Hono、Prisma/SQLite、Vitest/Jest、GitHub Actions。

## 实施与验证

1. 后端连接与目录：先添加旧协议在创建、导入、验证、目录和运行时解析中被拒绝的回归测试；删除专属适配器、认证、模型能力探测和 embedding 引擎。存量记录与对话关系保留。
2. 聊天运行时：先添加不再接受旧协议的请求构造测试；删除 Azure 路由、Ollama 流解析和 think 参数，覆盖主聊天、工具调用、标题、压缩、降级、Battle 与图片转写调用链。
3. 前端与契约：更新模板、连接编辑器、系统设置与 Battle，删除专属字段和控件；更新共享契约与各端调用，测试保留供应商的创建、保存和编辑流程。
4. 数据与文档：新增数据库迁移清理废弃专属字段和配置，不删除历史对话/连接记录；更新领域词汇及 ADR，说明旧服务需重新配置受支持协议。历史迁移保留以支持升级。
5. 验证：运行定向回归、各包类型检查、全量测试、架构检查及浏览器 DOM 交互/布局检查；两条独立审查轴检查规范与本计划符合度。
6. 发布：所有阻塞问题解决后提交，合并 main 并推送；监督对应提交的 GitHub Actions 质量检查和全部镜像任务通过。

## 数据替换说明

这是直接移除协议支持的破坏性变更。存量旧协议连接不会被调用、重新导入或编辑，历史对话仍可阅读。需要继续使用的服务必须重新配置为受支持的协议；不自动转移凭据或改写模型线路身份。

## 验证记录

- 后端全量：135 个套件、720 项测试通过；前端全量：82 个文件、475 项测试通过；移动端：3 个文件、8 项测试通过。
- 后端、前端与移动端类型检查通过；共享包构建与架构检查通过。
- 独立 SQLite 数据库执行全部 55 个 Prisma 迁移成功；专门回归测试验证旧连接禁用、凭据和历史会话/消息关联保留。
- 浏览器使用本地模拟 API，验证 320/390/768/1440 像素宽度的连接抽屉、键盘打开/关闭、填写及下一步，无页面或抽屉横向溢出；未读取截图。四种模板创建与编辑由 DOM 回归测试覆盖。
- 修复 Windows Prisma 测试数据库文件未创建导致的初始化失败，以及禁用连接组 ID 被误当成其他连接凭据 ID 的解析问题。
- 规范复审与实现边界复核通过；历史迁移和已授权纳入的研究文档保留。
