# 网页读取与任务追踪实施验收

实施分支：improve-web-retrieval。审查基线：18e1253963906faa9b0a539e74150ec6da1b715f。日期：2026-11-16。

## 改变了什么

搜索优先复用具有明确来源的提供方正文，摘要、预览、正文和历史版本保持各自含义。HTTP 与 Python 复用同一份 HTML；确认是 JS 骨架或验证页时直接尝试受限浏览器。单阶段超时继续使用剩余总预算，总预算耗尽与取消立即结束。Google Cache 已删除，Wayback 仅在显式历史用途参与。

URL 与 PDF 共享 Chromium：默认一个活动页面、两个排队请求、空闲 15 秒退出。网页阶段最多 8 秒，含排队和启动；准入、启动后及活动期间检查内存。默认容器内存上限至少 768 MiB、可用余量至少 256 MiB。Python 独立环境默认一个任务、两个等待请求、HTML 上限 1 MiB；冷启动 4000 ms、已就绪 1500 ms，均计入同一 URL 截止线。容器的硬内存限制仍由部署编排负责。

追踪日志使用持久化目录。噪声事件不再挤掉独立预算内的工具结果、错误和收尾事件；终止事件保留。文件缺失与完全损坏返回明确错误，部分损坏保留可读内容；首次刷盘前的运行中任务显示 pending，导出返回 TRACE_NOT_READY。数据库 eventCount 保持最终持久化事件数的原含义，省略和裁剪单独报告。

## 项目验证

- 后端完整 Jest：189 套件通过、1 套件跳过；1319 项通过、1 项跳过。Node 22 与本机 better-sqlite3 原生扩展匹配，PYTHON_RUNTIME_RECONCILE_ON_START=false；仅测试进程设置 NODE_NO_WARNINGS=1，排除宿主 EnvHttpProxyAgent 实验警告污染现有 Skill 的 stderr 空字符串断言。
- 后端与前端类型检查通过；前后端生产构建通过；Linux 入口脚本 bash -n 通过。
- 前端完整测试：172 文件通过、1 文件失败；1111 项通过、1 项失败。唯一失败是既有连接配置测试的 5 秒超时，独立重跑通过。新增导出错误处理 4 项测试通过。
- Python 适配器 24 项测试通过，真实 Trafilatura 2.3.1 smoke 通过；另有超时等待进程退出、排队时间计入截止线的针对性回归。
- Standards 与 Spec 两轴独立审查通过。公开读取入口覆盖阶段超时后回退、取消、缺 MIME、挑战页、新闻列表、短文、文档与图片路径；资源测试覆盖队列满、低内存、压力中止、崩溃后新旧槽位隔离、监听清理、去重与缓存参数隔离。

前期失败已据错误定位：Node 24 下两个未改动迁移测试因本机 SQLite 原生扩展 ABI 不匹配失败；改用 Node 22 后通过。Node 22 首轮全量有 1 条 Skill 测试因宿主实验警告失败；仅对测试进程关闭警告后全量通过。未修改这些迁移或 Skill 产品代码。

## 当前边界与部署下一步

Docker CLI 在当前宿主未安装，未执行镜像构建和容器重建验收；未部署生产。升级前按[部署说明](../deploy/web-retrieval.md)复制旧容器仍存的 task-trace／latex-trace 文件到持久化日志卷。已经丢失的事件仍需旧容器或备份恢复。

带多个独立时间戳块的滚动报道可能被标为 structured，文本仍保留。质量判定仍有最小字符阈值：极短文章与混合列表的选择需要后续样本校准，标题相关性未单独实现。结构化内容的准入在候选选择层完成，不复用纯散文的薄文本阈值。浏览器崩溃和渲染超时目前共用 BROWSER_UNAVAILABLE；HTTP 429 返回 Retry-After 元数据并停止本次来源请求，浏览器导航未提供相同状态码元数据。已有正文的搜索复用在自动阅读调度层完成，readUrlContent 的 providedContent 入口可独立使用，二者未改造成同一个调用路径。上述差异保留在验收中，未将摘要或预览升级为完整正文。
