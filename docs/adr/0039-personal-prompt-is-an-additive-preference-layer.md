# 个人提示词是偏好层，不替代全局系统提示词

系统提示词原先是四选一的短路链：`会话提示词 || 个人提示词 || 全局 chat_system_prompt || 内置默认`。这条链让个人提示词具备**替换**能力——任何登录用户写一句话，就能让管理员在 `chat_system_prompt` 里设的输出规范、合规约束与工具纪律整段消失，而界面上没有任何提示。

改为分层装配：

1. **角色层**：会话自定义 → 全局 `chat_system_prompt` → 内置默认（三者仍互斥，语义是"这段对话的角色设定"）
2. **偏好层**：`[用户个人偏好]` + `users.personalPrompt`，只要非空就追加为独立的 system 消息
3. **技能层**：web_search / deep_research / python_runner / task_planning 等注入
4. **格式层**：Markdown 输出规范

被否的备选：保留替换语义、另加一个"我确认要覆盖全局提示词"的子开关。否决理由是它把一个本不该存在的危险能力包装成选项，而绝大多数用户想要的只是"AI 更懂我的偏好"，不是"接管平台策略"。

后果：同时设了会话提示词与个人偏好的用户，偏好层从此开始生效（此前被会话提示词静默压制）。偏好层与角色层都是逐轮稳定的内容，因此 DeepSeek 前缀缓存命中不受影响。
