# ADR-0045：写作优先的输入区：模型与强度配套、工具收纳、单列搜索

- 日期：2026-11-15
- 状态：有效。取代 ADR-0043 中“模型选择以单列列表呈现”的界面条款（列表与搜索规则保留并沿用），并与 ADR-0044 的过程展示互不覆盖。
- 依据：用户确认 Figma 输入区重设计（docs/design/chat-composer-redesign.md）并批准分任务实施

## 决策

输入区以写作为主位，分四层：附件、编辑文字、已启用能力、底部操作栏。附件与已启用能力为空时整行收起。额度与键盘提示移出输入框，输入提示只提示写作或上传。桌面与手机共用同一组能力与模型控制，手机每个入口至少 44px，模型名可截断，发送与停止始终拥有完整点击区。

思考强度不再是独立下拉。模型与强度共用一个触发按钮和一个面板：按钮同时显示模型名与当前强度（手机用可识别短名，完整身份在 title 与可访问描述中）；面板内强度是模型列表的下一级视图，选择后返回列表。六值与 unset 语义沿用既有设置；用户选择默认后，同一会话刷新保持 unset。偏好更新用 null 清除已保存强度，聊天请求省略显式强度，后端继续使用系统默认；深度思考开关独立表达开关状态。组合模式选择模型后保留面板以便继续调整强度；未提供强度控制的旧入口保持选择即关闭。

能力与上下文收进单一工具面板：思考、联网、深度研究、Python，以及知识库、第三方技能与 MCP、会话系统提示词、自定义请求头、任务追踪。已启用能力在文字下方回显为可操作标签，联网标签仅在引擎支持范围设置时直达范围，否则打开能力页；思考标签直达强度设置；手机最多两个标签，其余汇总为 +N 打开面板。旧的 flat 控件行与“更多操作”菜单不再承载这些入口。面板里的能力勾选表示“本次会生效”（偏好开启且权限允许）：权限缺失时显示未勾选并禁用、给出既有原因，不写回偏好；已启用能力标签本来就按同一条件回显，两者与实际发送一致。

模型目录仍是单列、单一搜索、连接级唯一键、目录原顺序；不引入侧栏、来源筛选、推荐分组或自动路由。失败工作区文件保留在输入区并提供重试与移除，重试复用同一上传链路。可发送内容的含义固定为“文字 / 已就绪工作区文件 / 图片附件任一存在”：三者皆空时发送禁用且 Enter 不建会话（键盘与程序化提交同一守卫）；仅图片时发送既有图片载荷并附回退文案“请查看这些图片”，仅文件时为“请分析工作区中的文件”，图片与文字共存时各自按原语义提交。

手机壳读取 visualViewport 的高度与顶部偏移；工具与模型面板按同一可视高度滚动并避开键盘。关闭面板保留草稿。

## 权衡

把低频能力从常驻工具行收进一个面板，换取编辑区宽度与手机上的可点面积；代价是切换能力多一次展开。模型与强度合并减少一个入口并让当前状态可读，代价是面板多一层视图；因此保留“选择即关闭”的旧契约，避免非组合调用方被迫适应新流程。标签把状态外显，但需要上限与 +N 汇总，否则长内容与多能力在 375px 下会挤掉发送。输入提示不再承载额度，避免把额度当作写作提示反复干扰。

## 迁移

会话偏好更新 API 的 reasoningEffort 增加 null，表示清除会话覆盖；省略字段仍保留原值。使用现有可空数据库字段，无数据库迁移。强度枚举、聊天请求的默认回退、模型目录、权限与可用条件沿用。Web 输入区与欢迎页内部替换：欢迎页与聊天页现在都提供工具面板与组合强度入口；失去调用方的旧菜单与 flat 控件行直接删除，不保留兼容层。Battle 配置与重审、dev 预览继续使用纯模型选择器，契约不变。

## 验收

组件与 hook 回归测试覆盖：入口顺序、启用状态回显、额度在框外、空内容（文字/就绪文件/图片皆空）禁用且不建会话、图片-only 发送带图片载荷与回退文案、权限缺失时能力显示未勾选且不写回、创建中/生成中/停止、全屏、粘贴与附件移除、上传失败重试、输入法发送保护、手机 44px 与 +N、短名与可访问描述、思考标签直达强度页。前端完整测试、类型检查、lint、生产构建与 architecture 检查通过；真实页面验收在 dev 服务上用宽屏/390/375 覆盖默认、聚焦、禁用、模型与强度页、搜索无结果与错误、工具面板三视图、附件失败重试与生成中状态，截图与记录留在 output/playwright/。
