# ADR-0048：扩展能力归入统一设置侧栏

- 状态：接受
- 日期：2026-11-16

## 背景

工具与扩展在设置侧栏之外又显示一列段导航，MCP 和 Skill 内部还有标签，造成同屏导航重复。用户确认 Figma 方案，并授权在功能分支实施、验收后合并主分支。

## 决定

1. 工具与扩展改为设置侧栏分组，子页依次为总览、MCP 服务、Skill、内置工具、对话增强。移除内容区的段导航。
2. MCP 的安装模板、连接、凭据、工具、绑定，以及 Skill 的安装、待审批、版本、绑定保留为页内横向标签。
3. 扩展子页共用同一个页面组件，已访问内容常驻，侧栏往返保留标签和编辑草稿。弹窗与独立页的定位请求继续按宿主隔离。
4. 总览采用紧凑能力列表；空待办直接显示结果。业务状态、开关控制点、权限和保存逻辑保持原语义。手机目录使用现有 Sheet 抽屉，复用焦点管理、Escape 和遮罩关闭。
5. 设置目录按确认的设计使用桌面 40px、手机 44px 行高，252px 侧栏和 284px 抽屉；内容边距桌面 48px、手机 20px。目录行是 ADR-0042 桌面控件高度集合的局部例外。当前导航用 signal-soft 浅底、signal-text 文字和信号条，保持已确认的青绿色选中态；颜色使用独立语义变量，避免品牌 primary 覆盖降低文字对比度。

## 迁移与取舍

新增 extensions-mcp、extensions-skills、extensions-tools、extensions-extra 叶子；extensions 继续打开总览。原 extensions:* 卡片标识保持，搜索注册表把卡片归属更新到子页，旧入口携带卡片时解析到同一子页。无需数据迁移。

统一侧栏让内容获得更多宽度；侧栏增加四个子项，通过可展开分组和手机抽屉控制占用。内容常驻保留原有草稿行为，访问过的能力仍占用 DOM。

总览的待办只统计待审批的 Skill 调用。连接类型没有“必须鉴权”的声明，未绑定凭据的 MCP 连接显示为信息提示，允许无需鉴权的连接留空；不再把它们计为待办。读取失败显示未知状态。
