# ADR-0044：本轮工作区与可追溯工具操作

- 日期：2026-11-14
- 状态：已实施并完成独立审查；发布门禁与取舍见 docs/superpowers/reports/2026-11-14-process-workspace.md
- 取代：ADR-0043 的 Web 过程展示部分；模型选择与 Android 展示不变

## 决策

答案保持阅读主位，消息摘要入口打开同一套本轮工作区。工作区分过程、来源、产物；模型返回的推理文本与执行日志分开。宽屏使用 440px 侧栏，中屏覆盖，手机全屏；关闭后恢复触发位置。调用台账只处理当前消息，支持搜索、筛选和原始明细。

操作身份使用事件 id；callId 只用于寻找父候选，parentCallId 唯一命中才连线。不同 id 不因共用 callId 合并，孤儿和歧义单列。结果、拒绝、未执行、降级恢复分别计数；没有实际证据就不显示尝试次数。共享纯函数由 Web、历史投影和未来客户端复用，避免每个界面另算统计。

工具日志仍存现有 toolLogsJson，写入 v2 信封：entries、coverage，以及可选 runResult。coverage 将 trace、persisted、projection 分为三层，各自 complete / partial / unknown；裁字段与丢记录分别计量。历史列表精简不同于原记录缺失，打开工作区按需请求完整 progress/by-client 消息。旧数组继续读取，但覆盖保持 unknown。存储裁剪仅写 storageTruncated 并计入覆盖；工具自行报告的 truncated 保留执行截断语义，不把刷新后的存储损失误算为运行降级。

POST /api/chat/stream/stop-tools 仅置当前活动 run 标记，无 pending 注册、不终止在途工具。随后至多请求一次不含 tools/functions 的最终回答；未执行的已提出调用补合法 aborted 工具结果。取消优先，Battle 预算默认维持原 error 行为，聊天显式选择 finish。回执仅表示受理，最终结果来自执行事件。stopReason 与 finalAnswerGenerated 通过 SSE、解析器、日志信封和历史消息保持一致；false 时保留已有正文并提示未生成最终回答。

执行命令只在可控的聊天轮次展示；分享和 Battle 的共用工作区保持只读。Battle 输出详情内联展开过程且默认收起，避免在详情对话框上自动叠加第二个模态。已有真实研究计划确认继续走现有接口；整轮重新生成明确标注，不冒充单工具重试。

来源按 URL 去重；清单顺序号不等于正文引用编号。当前渲染器没有可验证的引用锚点映射，因此来源直接外链，不显示无实际定位能力的按钮。父任务筛选保留必要祖先上下文，不把匹配的子任务扁平化为新的父调用。

## 权衡

放弃一条无限增长的推理/工具平铺流，以父子结构、异常分组和独立台账降低阅读负担。覆盖元数据增加存储结构，但避免用不可比较的事件更新数、最终记录数和工具请求数推算成功率。无数据库列迁移，runResult 跟随日志同次保存，避免刷新后猜测收尾结果。

## 迁移

Web 过程入口直接替换旧时间轴。v2 写入、旧数组可读属于既有历史数据读取需要，不维护第二套展示。删除没有执行效果的 /api/chat/stop；现有 stream/cancel 保持整轮取消。保留披露偏好的消息作用域和 share/Battle 隔离。

## 验收

共享操作投影、512KB 裁剪、历史/分享/Battle、停止与取消竞态、无工具收尾和消息水合均有回归。项目 dev 服务上验收桌面与移动的真实组件、键盘焦点、来源产物、长内容和异常。Trace97 仅使用原导出保留的十条脱敏明细；454 条压力夹具明确标为合成，不冒充完整原始事件。
