# ADR-0043：简洁模型选择与过程渐进展开

- 日期：2026-11-14
- 状态：已实施并验收
- 依据：用户确认 Figma 设计后明确同意全面改造

## 决策

模型选择以单列列表呈现，每项只保留模型名称、供应商身份和当前选择。搜索同时匹配模型名称和供应商。移除厂商侧栏、收藏/最近/能力筛选及重复常用区。模型连接级唯一键、选择回调、既有调用方约束和错误恢复不变；同名模型来自不同连接时仍可区分。

Web CoT 完成态默认压成状态、耗时和“查看过程”的一行摘要。运行时展示当前活动；用户按需打开步骤和现有详情，按原始事件顺序排列。提纲首屏最多7步，其余通过查看更多展开，取消提纲层的内部限高滚动。级别、已披露步数及单步详情的消息级记忆继续有效，虚拟列表卸载后可恢复。失败入口按需披露至首个失败节点并聚焦、展开真实失败详情；普通展开仍从7步开始。Battle显式全部展开和现有步骤内容继续有效。Android本轮保持现状。

## 权衡

移除多维筛选，降低首次选择负担；大量模型依靠单一搜索定位。用户每次只处理一条选择路径，供应商始终可见。长过程不再把答案推离首屏；查看更多代替嵌套滚动，逐步详情保留追溯能力。

## 迁移

Web选择器内部直接替换，无后端或数据库迁移。收藏/最近等旧内部展示逻辑不再使用，不改变账号偏好模型。已有调用入口与连接数据含义不变。

## 验收

相关组件回归测试、前端完整测试、类型检查和lint；项目dev服务上检查宽屏和375px、模型选择/供应商搜索/键盘/无结果/加载错误/长文本，以及CoT默认折叠/展开步骤/查看更多/运行/失败。截图和运行记录留在 output/playwright/。
