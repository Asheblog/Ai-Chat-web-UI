# ADR-0046：网页读取复用提供方正文并限制本地提取资源

- 状态：接受
- 日期：2026-11-16

## 背景

自动搜索已经可能取得提供方正文，但再次读取源站增加延迟与失败机会。原串行后备路线会耗尽总预算，且关键词判断挑战页存在误判。服务器资源有限，URL 读取与报告 PDF 分别启动 Chromium 会叠加内存峰值。

## 决定

1. 保留 read_url 和搜索自动阅读入口。正文、结构化内容、摘要和存档分别保留来源及时间；提供方合并时正文来源独立于命中引擎列表，摘要不升级为正文。
2. Node 管理网络、总截止线、取消与后备路线。Trafilatura 在受控 Python 进程中处理已下载 HTML，不拥有第二套下载队列。依赖使用应用专用、锁定的构建环境，与可由管理员管理的 Skill Python 环境分离。
3. URL 读取与 PDF 报告共用 backend 进程内浏览器池。默认单页面并发、两个排队请求、空闲 15 秒回收。请求结束关闭独立 context；取消不影响其他任务。
4. 浏览器在准入及启动后读取 cgroup v1/v2 可用内存。默认容器上限至少 768 MiB、可用余量至少 256 MiB；不满足时跳过渲染并保留原因。此检查是准入保护，容器总内存硬限制由 Docker / 1Panel 执行。
5. 单 URL 总时限保留既有含义；自动阅读新增独立批次截止线，包含排队、替补和所有读取。每个阶段只使用剩余时间，不在超时后叠加长任务。
6. 同 URL 工作合并与缓存均有容量上限，保留有语义的 URL 参数。当前内容跳过普通正文缓存；共享任务的一个订阅者取消不终止其他订阅者。
7. 一次工具操作聚合内部 attempts，恢复成功按最终内容结束；缺失、丢弃、裁剪与历史快照状态不得伪装为完整执行或当前正文。追踪沿用 ADR-0044 的 operation identity 和 coverage 契约。
8. 网页配图归属对应的 `read_url` 结果，不生成用户消息。支持视觉和图片型工具结果时，OpenAI Responses 发在对应 `function_call_output` 内，Anthropic 发在对应 `tool_result` 内。每张图紧跟其原文标题、页面 URL 和图片 URL。Chat Completions 等纯文本工具结果只传正文和候选图片链接；搜索自动阅读也按各新闻条目保留图片链接。候选图可能是二维码、标识等站点素材，网页标记不证明它就是新闻配图。
9. 若模型请求含可选网页配图，且上游返回 HTTP 400，错误消息同时包含 `business code 11135` 和 `could not process an image`，只去掉工具结果内的视觉图片和随图标签，在原模型轮次重试一次；本次回复后续只传原图链接。工具结果里的正文、来源链接和调用 ID，以及用户上传的图片均保留。直接读取的图片资源同样归属工具结果；支持时发送图片内容，其余协议保留原图链接，不受可选网页配图重试影响。追踪记录请求图片数和重试影响的工具结果数，不记录图片内容。

## 术语

- Web Evidence（网页证据）：从明确 URL 取得的正文或结构化内容，携带来源和获取时间；摘要与历史快照保持独立种类。
- [Optional Page Images（可选网页配图）](../../GLOSSARY.md#搜索)：附在对应网页工具结果上的视觉证据，与用户附件分离。
- Read Attempt（读取尝试）：一次读取内部实际执行的阶段，保留引擎、耗时、结果与错误。
- Automatic Reading Batch（自动阅读批次）：受独立总截止线约束的候选读取、排队与替补过程；替补不改变原 URL 的结果。
- Browser Work Slot（浏览器工作槽）：网页与 PDF 共享的页面配额，每个任务使用隔离 context。

## 取舍与影响

共享浏览器降低启动成本，但要求隔离 context、受控队列与崩溃恢复；小容器下部分 URL 会跳过浏览器而使用其他可用提取能力。独立 Python 环境增加镜像体积，却避免管理员维护 Skill 依赖时误删内置能力。

外部提取服务保持显式配置与费用开关；首先复用已有搜索结果，不自动开通新服务。Google Cache 删除，Wayback 仅接受显式历史用途。

## 迁移

无需数据库迁移，既有工具 URL 参数仍有效，默认取当前内容。历史读取通过可选 purpose=history 指定。镜像构建包含正文提取环境；既有 Node 阅读和浏览器入口不以新增 Python 能力就绪为条件。日志目录迁移到持久化卷；已经丢失的旧事件应明确报缺失，不能以空导出代替。
