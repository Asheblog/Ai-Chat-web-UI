# 扩展安装由模型工具触发，安装模板权限仍归管理员

"装一个扩展"从设置页面表单改为模型可调用的工具 `install_extension`：模型识别用户意图后调用，服务端完成链接解析、白名单清单探测、类型判定与安装。为避免普通聊天被拖进工具循环，只有消息中出现 GitHub 仓库链接时才激活该工具。

权限沿用既有边界：MCP 安装模板（`McpInstallation`）仍只由管理员创建（ADR-0017），普通用户基于既有模板创建自己的连接；Skill 安装仍走用户私有链路与审批。工具不得接收明文密钥，只返回所需的密钥名称，由用户在凭据中填写。
