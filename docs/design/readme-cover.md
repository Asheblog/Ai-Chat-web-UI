# README 封面

[查看 Figma 可编辑设计稿](https://www.figma.com/design/g8OE79vEs53TGlcJ6Q4Cva?node-id=14-707)。

封面用于 [项目首页](../../README.md)，尺寸为 1600 × 840。左侧突出“把对话，变成成果”，右侧以工作流程示意展示提问、工作区状态、来源计数和 PDF 产物。示意内容用于解释能力。

设计沿用 [Ink & Mist](../adr/0042-ink-and-mist-neutral-first-design-system.md)：雾白画布、墨黑主文字与按钮、青瓷信号色，Source Sans 3 配合系统中文字体。主要信息为原生可编辑文本和图层。

- 设计文件：Figma `g8OE79vEs53TGlcJ6Q4Cva`，页面 `0:1`，画板 `14:707`。
- 导出图片：[readme-cover.png](../assets/readme-cover.png)，PNG，1× 导出。
- 创作脚本：[readme-cover.figma.js](readme-cover.figma.js)。脚本用于在当前 Figma 页面新建画板；同名画板存在时停止，日常修改直接编辑现有画板。

更新封面后，从 Figma 导出此画板为 1× PNG，替换仓库图片，并检查中文字体、文字换行和完整画板的渲染效果。
