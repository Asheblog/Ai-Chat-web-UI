- `composer-matrix.json`：12/12 通过。欢迎页与会话页 × 1440 / 390 / 375 × 浅色 / 深色；默认、聚焦、有草稿、悬停、空输入禁用、模型搜索 / 连接身份 / 六档强度 / 默认值、工具四项能力 / 七项范围 / 思考标签直达 / 标签溢出。手机会话另实测至少44×44px、四入口无重叠、520px 可用视口内编辑区和发送可见。
- `boundary-matrix.json`：3/3 通过。普通用户受限能力、管理员任务追踪边界、1280×520 桌面面板滚动 / 焦点 / 返回 / 关闭；无页面异常或资源失败。
- `model-collision.json`：通过。将触发器临时移到屏幕顶部验证 Radix 向下避让；这项是定向布局实验。
- `context-matrix.json`：欢迎页与会话页1440 / 375，共4/4通过。知识库选择与会话写回、Skill / MCP、提示词保存、请求头与草稿保留均通过；没有意外控制台异常、资源失败或未覆盖接口。
- 欢迎页与会话页1440 / 375：图片选择、粘贴、拖入、移除、全屏应用与取消通过；会话最终定向结果保存在 `attachment-session.json`。手机全屏入口沿用桌面共享编辑对话框。
- `upload-desktop.json` 与 `attachment-session.json`：桌面与手机上传中 → 故意注入503 → 重试成功 → 移除 → 输入法组词防误发 → 换行 → 发送 / 停止均通过；503 是唯一预期资源错误。

真实浏览器发现手机工具栏模型列覆盖附件 / 工具、欢迎页空输入发送未禁用、会话知识库本地选择被旧会话记录还原，以及手机缺少全屏入口。原实现者已修复；12组合矩阵、会话知识库写回、手机全屏与附件恢复均已定向通过。Next.js 开发指示器曾遮住手机附件入口，验收页隐藏开发浮层后文件选择正常。

手机连续上下文场景另发现工具抽屉与提示词对话框同时打开，抽屉拦截保存按钮。原实现者在 `44939616` 统一四个上下文入口的浮层切换顺序；最后375px场景定向复验通过。

## 独立审查后的补验

Task 3 独立审查发现的空 Enter、纯图片发送、知识库裁剪循环与交错写回均已修复。最终补验：

- `review-regressions.json`：7/7。欢迎页 / 会话页 × 1440 / 375 实测纯图片请求含图片字节、MIME 与回退文案；空 Enter 不建会话；375px长错误下重试 / 移除均44px且在编辑框内、重试恢复；陈旧知识库ID无渲染循环；受限能力显示禁用且未勾选、原偏好保留。
- `context-final.json`：4/4。共享浮层交接后知识库、Skill / MCP、提示词、请求头及草稿保留通过。
- `spacing-final.json`：4/4。恢复4px步进后，两路由 × 1440 / 375复验模型搜索、完整长名、同名连接、六档强度、工具页签、七范围与标签溢出；首次冷编译等待超时，路由编译完成后复验通过。
- `final-contracts.json`：5/5。1440 / 375系统Medium下选择High再默认、保存null、刷新保持默认、聊天请求省略reasoningEffort；非Metaso联网标签返回能力页；欢迎页与会话页模拟480px可视高度/32px顶部时，输入区、发送、模型和工具面板均在可视范围内，Enter / Space各切换一次。

最后一项首次实测发现Tailwind高度规则覆盖可视高度，已提高壳选择器优先级并复验。附件首次补验用了不存在的容器类，欢迎页fixture首次复用了会话ID；修正fixture后重跑，未将这些初始失败计作产品通过。503仅为上传恢复场景主动注入。

整支路Standards / Spec独立报告已逐项裁决。增量复审代理连续失败且无交付，最终闭环由root对照原报告、代码与上述证据完成。范围入口、默认强度、键盘视口、无调用props、长名文档均已修复；原4px间距要求恢复到代码，撤销2px例外。

## 工程检查

最终修复候选：前端全量172文件 / 1111测试通过；后端172套 / 1081测试通过；前后端类型检查、全量Lint、架构检查和生产构建退出码均为0，静态页13/13生成完成。后端首次全量因宿主UNDICI实验警告导致stderr断言失败，设NODE_NO_WARNINGS=1后完整通过。Lint有124条仓库既存警告；文件行数检查仍因既有超限退出1，阈值未调整。4px间距恢复后，定向组件测试与四路由浏览器复验通过。合并后全量复验曾出现1项交接时序断言失败（其余1110项通过）：测试等待DOM期间真实220ms已过去。改为可控时钟，分别验证关闭、219ms未调用、220ms调用一次，产品交接逻辑未变；修正后定向用例与完整172文件 / 1111测试全部通过。
