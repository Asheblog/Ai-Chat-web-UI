# 输入区重设计：写作优先，工具按需展开

日期：2026-11-15。阶段：用户已批准，作为输入区实施与验收基线。

[打开 Figma 主稿](https://www.figma.com/design/tbkaIC3w5FVZrawBKs8BYb/Untitled?node-id=1-2) · [竞品研究](./chat-composer-reference-research.md)

## 先看双端主稿

输入区分为附件、文字、底部操作栏三层。没有附件时，附件行收起；默认态保持紧凑。桌面底部从左到右是附件、工具、已启用能力图标、当前模型与强度、发送。手机模型入口移到顶栏正中，底部其余操作保持单行。

- 额度移到框外，输入提示只提示写消息或上传文件。
- 附件保留独立快捷入口，继续支持图片、文件、粘贴与拖入；已附文件显示名称、类型、状态和移除操作。
- 思考、联网、Python 等本次可用且启用后用图标回显，保留提示与可访问名称；按实际剩余空间显示，放不下的条目汇总为 +N。点图标打开相应控制，+N 打开已启用能力。权限暂不可用时面板显示未启用的禁用开关和既有原因，保留用户保存的偏好。
- 工具面板承载能力及上下文设置。桌面锚定浮层；手机底部面板，用“能力 / 上下文与设置”分组。
- 模型与思考强度共用入口。桌面紧邻发送，浅灰胶囊完整显示模型名与当前强度，例如“DeepSeek V4.1 Flash Max”；手机在顶栏正中使用可识别短名。列表保留完整名称、供应商与连接来源，搜索沿用现有匹配规则。
- 发送使用墨黑主按钮；文字、就绪文件和图片均为空时禁用，按钮与 Enter 使用同一可发送判定。纯图片消息沿用图片载荷并使用“请查看这些图片”作为无文字时的提示；纯文件消息沿用“请分析工作区中的文件”。生成中切换为停止。编辑锁定、模型能力、权限和计费条件继续使用现有规则。

## 功能对应

| 现有功能 | 新位置 |
| --- | --- |
| 上传、图片、工作区文件 | 左下附件快捷入口；已附内容位于文字上方 |
| 知识库 | 工具 → 上下文与设置 → 知识库 |
| 思考、联网、深度研究、Python | 工具 → 能力；启用后回显图标 |
| 搜索范围 | 点击联网图标进入范围设置；现有范围枚举和可用条件保留 |
| 思考强度 | 模型选择器底部 → 思考强度；思考图标也可到达该设置 |
| 第三方 Skill 与 MCP | 工具 → 上下文与设置 → 第三方技能与 MCP |
| 任务追踪 | 工具 → 上下文与设置 |
| 会话系统提示词、自定义请求头 | 工具 → 上下文与设置 |
| 模型选择、搜索 | 桌面发送旁模型按钮与浮层；手机顶栏居中按钮与底部列表 |
| 全屏编辑 | 有内容时编辑区右上角 |
| 发送、停止、额度 | 右下主按钮、框外额度提示 |

## 响应式与视觉规则

- 沿用项目 Ink & Mist：雾白画布、白面板、墨黑主操作、青瓷信号色；仅悬浮模型菜单使用轻阴影表达层级。
- 编辑文字 16px；操作文字 13–14px；辅助文字 12px。Figma 使用可用的 Noto Sans SC；实现时沿用项目 Source Sans 3 + 系统 CJK 字体栈。
- 外框圆角 16px；按钮和附件 8–10px；间距以 4px 为步进。
- 手机底栏按钮高度 44px，附件移除、全屏、能力图标与 +N 的点击区域至少 44px。
- 编辑区随内容增长，到上限后内部滚动。手机软键盘出现后输入区贴可视视口底部；工具面板按可用高度滚动，关闭后恢复焦点和草稿。
- 桌面模型触发器按内容显示完整名称与思考强度，模型选择面板宽度保持原值；手机短名在顶栏可用空间内显示。发送按钮不收缩。
- 桌面 Enter 发送、Shift+Enter 换行；中文输入法组词期间沿用现有发送抑制规则。

## 模型选择器：结合用户提供的 GPT 网页截图

[打开双端模型选择稿](https://www.figma.com/design/tbkaIC3w5FVZrawBKs8BYb/Untitled?node-id=5-558)

借鉴截图中的灰色胶囊、单列轻菜单和右侧勾选。上版的选中大色块、模型 ID 副标题和大面板已替换为较紧凑的列表。

- 桌面浮层宽 288px，右边与模型按钮对齐，展开稿中距离按钮 8px；默认向上展开，实际页面按可用空间翻转。常规名称一行展示，少量长名称换行。
- 模型行常规高度 48px，主文字 14px，来源文字 12px。长名称完整换行并增加行高；来源保留供应商与连接名，以区分同名模型。
- 当前项显示勾选，鼠标悬停使用浅灰底；两种状态独立。
- 保留单一搜索入口和目录原顺序；不新增侧栏、来源筛选、推荐分组、自动模型路由或重复常用区。
- 手机改为底部面板，搜索与标题固定，列表区域独立滚动；保留 44px 关闭区域与底部安全区。
- 选择模型后保留面板，可继续调整思考强度；点关闭、外部区域或 Esc 返回输入区，保留草稿。点击底部“思考强度”在同一面板切换到选项列表，选择后返回模型列表，触发按钮同步显示新值。
- 强度保留“默认、Low、Medium、High、XHigh、Max”；“默认”对应现有 unset（不显式设置）。Max 是稿中的示例选择值，实际初值读取当前设置。可用条件与提交含义继续沿用现有规则；深度思考开关仍独立表达开关状态。
- 工具面板中的重复强度入口已移除。模型名与强度是同一按钮内的两个独立文本值，强度不写入模型标识。
- 模型名取自用户参考图和布局样例，实际目录来自账号配置。原有连接级选择身份、调用方限制与恢复规则继续有效。

已将胶囊按钮同步到主稿和输入状态稿，将工具画板的旧模型面板替换为新版。实际导出图已检查桌面锚点、390px / 375px 面板、勾选、悬停、聚焦、长名称、同名连接、搜索无结果、加载和重试；键盘导航与滚动行为由实现阶段验证。

## 设计依据与实施边界

采纳 Claude / Gemini 官方说明支持的菜单收纳和当前选择可见原则。根据用户明确反馈，模型与强度合并选择并配套显示，桌面菜单收窄为 288px；附件保持独立快捷入口。强度的取值和提交含义继续沿用现有设置。

本设计基线包含 Figma 原生可编辑图层与静态状态稿。应用接线、软键盘/屏幕阅读器/浏览器行为、深色主题和真实长模型名适配按实施计划验收；实际覆盖与结果记录在浏览器验收文档中。模型列表以账号配置为准。
