# Ink & Mist · 完整界面与组件规范

日期：2026-11-14。延续 ui-redesign-ink-mist.md 的中性色、青瓷信号色与现有业务契约。用户本轮要求先在 Figma 完成细节，再全面落地前端，非仅换色或修单一错位。

## 完成标准

1. 输入区：宽屏工具组在左，当前模型与发送/停止操作独立靠右；动作栏 Fill，模型长名称截断，发送不被压缩。窄屏保留可用触控尺寸、工具溢出策略与安全区；禁止整栏水平溢出。初始、输入中、附件、生成中、禁用状态有明确视觉。
2. 模型选择器：触发器显示当前模型，模型数据身份和选择回调不变。桌面 600px 上限、144px 模型家族分组栏，搜索/全部/最近/收藏与能力筛选保留；行显示名称、连接来源、能力、上下文，收藏与选择分离。支持键盘、焦点回归、长名称、无结果、无模型、加载和请求错误；移动使用有标题和关闭的抽屉。
3. 全站页面：会话、个人与系统设置、模型连接、工具、用户、系统数据、高级设置、对战步骤/结果、日志/追踪、登录注册、公开分享、弹窗均遵循同一层级和间距。保留已有实际功能与保存机制，不加假控件。
4. Figma：修复原页面约束；新增原生组件和关键状态，不用图片代替编辑图层；宽窄屏与明暗模式检查实际截图。保留已有页面与设计内容。
5. 实现：组件化修改而非全库字符串替换。公共样式集中，已有无障碍、模型能力、权限、上传、流式响应和状态恢复语义保持。
6. 验证：项目全量前端测试、类型与生产构建；真实浏览器检查关键页面/交互/长文本/空与错误/移动/暗色，记录截图与未验证项。独立 Standards/Spec 审查后才推送 main，并监督 CI。

## 设计决策

- 不重开视觉方向：使用墨色主操作、白色/雾色层级、青瓷仅用于状态。
- 模型选择按现有模型家族分组（不是连接分组），连接作为来源信息；复合 key 区分跨连接同名模型。上下文/能力仅在模型真实字段存在时显示，稿件不引入价格等未实现业务值。
- 保留每页原有保存边界：个人资料等逐项即时保存；高级/推理网络等原有批量显式保存继续保留。新增布局不添加全局假保存条；系统导航和页内导航职责保留。
- 组件交互按可用性调整：移动触控目标至少44px，键盘焦点可见，禁用状态不过度褪色；长内容可滚动且关闭入口始终可达。

## Review Focus

- 320/390px 输入区：长模型名、全部工具开启和上传附件不挤出发送动作。
- 多连接下相同 model id：必须按现有复合 key 保持身份，收藏/最近正确。
- 键盘：搜索、分组、模型选择、收藏、Escape 与弹层关闭焦点恢复。
- 深色/品牌换色：局部颜色仍来自语义变量；不把 signal 软色与墨色主操作混淆。
- 浏览器证据要区分真实页面与测试 fixture，已加载模型和实际消息必须覆盖，禁用首页不算完整聊天验收。
