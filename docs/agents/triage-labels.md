# Triage Labels

本仓库保留五个默认 triage 角色，角色名与 GitHub 标签名一致。

| 技能中的角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格充分，可交给代理实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 决定不推进 |

技能提及某个角色时，使用表中对应的标签。何时添加、移除或流转标签，遵循当前技能的规则。

## Wayfinder 标签

| GitHub 标签 | 用途 |
| --- | --- |
| `wayfinder:map` | 探索地图 |
| `wayfinder:research` | 研究工单 |
| `wayfinder:prototype` | 原型工单 |
| `wayfinder:grilling` | 决策访谈工单 |
| `wayfinder:task` | 探索任务工单 |

这些标签供相应技能使用；初始化只补齐标签词汇，后续按技能要求选择标签，不额外强制标签。
