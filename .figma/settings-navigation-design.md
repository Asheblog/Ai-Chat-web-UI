# 工具与扩展：统一设置导航

设计文件：https://www.figma.com/design/g8OE79vEs53TGlcJ6Q4Cva?node-id=6-2

实施分支：`feat/settings-unified-navigation`，基线为 `3c02a205`。应用已按本方案完成统一侧栏、横向标签、紧凑总览与手机目录抽屉，验收证据见本仓库 `output/playwright/settings-nav/`。

## 导航与内容的分工

设置左侧保留一棵导航树。「工具与扩展」作为可展开的分组，其子页面依次是总览、MCP 服务、Skill、内置工具、对话增强。删除内容区域的独立 SectionRail，让内容区直接呈现当前页面。

MCP 的安装模板、连接、凭据、工具、绑定属于 MCP 页内切换；Skill 的安装、待审批、版本、绑定属于 Skill 页内切换。这两组使用横向标签，不再增加第二列垂直导航。现有搜索定位与卡片深链在实现时应映射到相同页面和标签。

## 视觉与行为

沿用项目 Ink & Mist：雾色侧栏、白色内容面板、墨黑主按钮，青瓷色只用于当前导航、状态和开关。字体为 Microsoft YaHei，正文以 14px 为主，桌面页标题 28px，手机页标题 24px。

桌面侧栏宽 252px，二级项缩进，与父级区分。桌面内容区域左右内边距 48px。手机改用 284px 目录抽屉，内容左右内边距 20px。可编辑图层使用 Auto Layout 组织。

总览由大卡片改为能力列表，状态与数量集中对齐；空待办仅显示一条结果。MCP 首次使用只保留中央的新建操作，避免同屏重复主操作。Skill 安装页删除对顶部标签的重复说明。

MCP 全局开关、动态 Skill Runtime 开关、AI 自助安装开关保留现有业务语义。总览的能力状态继续来自实际设置；待办只统计待审批调用。连接模型没有“必须鉴权”的字段，未绑定凭据显示为信息提示，不把无需鉴权的连接记成待办，也不把零连接解释为已绑定凭据。

## 证据与实现验收

已检查五张最终渲染：桌面总览、MCP 空态、Skill 安装、手机总览、手机目录抽屉。五张画板的结构检查未发现子节点溢出。已设置 10 个页面跳转原型链接，覆盖三个桌面页面的侧栏互跳、总览进入 MCP/Skill，以及手机目录开合。

原型演示上述导航；实现保留原有表单提交与开关保存路径。完整前端回归通过 179 个文件、1,181 项测试。真实浏览器在 1440px 与 390px 的浅色、深色主题下覆盖全部系统叶子、MCP/Skill 标签、搜索卡片定位、草稿往返及抽屉关闭后的焦点；另检查加载、错误重试与 358px 总览。浏览器验收使用 API 夹具，未验证真实后端写入与 320px 视口；权限和宿主隔离由组件测试覆盖。最终浏览器报告位于 output/playwright/settings-nav/FINAL-REPORT.md。
